【のぼれ！無限の塔】完成版プロトタイプ

■起動方法
1. ZIPを展開します。
2. index.html をダブルクリックします。
3. Chrome / Edge / Firefox の最新版で動作します。

■ファイル構成
すべて同一フォルダにあります。サブフォルダは使用していません。
- index.html : ゲーム画面
- style.css : 全デザイン、レスポンシブ、演出
- data.js : 敵32種、装備、キャラクター、実績等のデータ
- game.js : 戦闘、成長、ガチャ、ショップ、セーブ等
- background.png : 戦闘背景
- heroes.png : キャラクター画像シート
- enemies_01.png / enemies_02.png : 敵画像シート

■主な機能
- 自動戦闘、手動攻撃、3倍速
- 32種類の敵、雑魚、中ボス、ボス
- 階層進行、6ワールド
- レベルアップ、経験値、会心、DPS
- R / SR / SSR / UR装備
- 装備ドロップ、装備変更、おすすめ装備
- ガチャ、100回天井、10連割引
- アイテム、ショップ、仲間、図鑑
- デイリーミッション、実績、転生
- 最大8時間の放置報酬
- LocalStorage自動セーブ
- PC / スマートフォン対応

■注意
ブラウザの閲覧データを削除するとセーブデータも消えます。
社内配布や本番公開では、サーバー保存・ユーザー認証・改ざん対策の追加を推奨します。

■v7 操作修正
- 攻撃ボタン長押し連射を完全撤去。1タップ=1回攻撃。

- 通常の装備ドロップからモーダル表示を撤去。小型通知のみへ変更。
- ガチャ結果は重要な獲得結果なので従来どおり結果ウィンドウを表示。


■v8 スマホレイアウト全面再構築

- 中央領域を「常時表示バトル / 独立スクロールコンテンツ」の2段へ分離。
- バトル画面は常に表示し、レベルアップ・装備・アイテム・ガチャ・ショップの中身だけ縦スクロール。

- 370px以下の小型スマホにも専用寸法を設定。

- 既存の戦闘、120敵、12キャラ、装備6部位、ガチャ、遠征、迷宮、神器、鍛冶、シーズン等のロジックは維持。


■v9 操作レスポンス・デバッグ調整
- 全ボタンの押し込みを約28～45msへ短縮し、「ポチッ」と押した瞬間だけ反応する触感へ変更。
- 長いtransform/filter/box-shadow遷移を上書きし、押下アニメーションのもたつきを削減。
- 攻撃ボタンは約22msの短い押下表現へ変更。
- 下部5タブは約25msの短い縮小フィードバックへ変更。
- レベルアップ長押し機能は維持しつつ、単押しアニメーションのみ高速化。
- DEBUG用としてガチャチケット所持数を起動時に最低10,000枚へ一時変更。既存セーブでも10,000未満なら自動補充。


■v10 ボタン・装備画面再構築
- ボタン押下アニメーションを既存CSS継ぎ足しではなくtap-pop方式に再構築。約88～96msで押して戻るだけの短い表現。
- :active由来の長い押し込み・brightness・shadow遷移を全撤去。
- キャラクター画像に使っていたhue-rotate等の色フィルターを削除。キャラ選択・ガチャ結果・装備画面すべて原画色で表示。
- キャラクター変更入口をレベルアップ画面から撤去し、装備画面へ移動。
- 装備画面をキャラクター中心のマネキン形式に刷新。キャラ周囲に武器・服・ズボン・アクセサリー・ブーツ・グローブの6スロットを配置。
- 各装備スロットを押すと、その部位だけの交換一覧へ遷移。戻るボタンでキャラクター装備画面へ復帰。
- 装備による攻撃＋、HP＋、総戦力、攻撃速度、会心率、装備数を一覧表示。
- デバッグ用のガチャチケット10,000枚強制補充処理を完全削除。

■v14 ボタン操作・報酬一括受取
- ボタン押下アニメーションを全面撤去。transform / scale / brightnessアニメーションを使用しない構成へ変更。
- 押している間だけopacityを少し下げ、内側の白枠を表示。「押した」と分かるだけの即時フィードバックへ統一。
- 攻撃ボタンも位置移動・縮小・跳ね返りを完全撤去し、押下中の色変化だけに変更。
- デイリーミッションに「一括受取」を追加。
- 実績に「一括受取」を追加。
- 冒険依頼に「一括受取」を追加。
- シーズンジャーニーに「一括受取」を追加。
- 一括受取時は、条件達成済みかつ未受取の報酬だけを安全に集計して付与。


■v15 ボタン・長押し・報酬ヘッダー修正
- 過去に追加されていたボタン用animation / transition / opacity / transform表現を最終CSSで全面リセット。
- 押下時は移動・縮小・フェードを行わず、内側に約2pxの明るい枠と約10%の暗色オーバーレイだけを表示。
- 攻撃ボタンも位置やサイズを一切動かさず、押下中の内側リングと約13%の暗色だけで反応を示す。
- HP、攻撃、攻撃速度、防御、会心率、会心ダメージ、ドロップ率、獲得ゴールドの各ステータス強化ボタンに長押し連続強化を追加。
- ステータス強化は単押し1回、380ms長押し後は120msごとに連続強化。指を離すと即停止。
- 報酬画面のモーダル上部に専用余白を確保し、閉じるボタンと一括受取ボタンが重ならないよう配置を分離。


■v16 モーダル・武器合成・タップ操作修正
- 報酬画面はタイトルを1行固定。右上に閉じる(X)、その真下に一括受取を縦配置。
- 武器交換画面に「武器合成」を追加。同じ武器・同じ強化値3個を素材にして強化値+1の武器へ合成。装備中武器は素材から除外。
- 連続タップ拡大対策を整理。touchendでのpreventDefault連打、dblclick抑止、gesturestart抑止をJavaScriptから撤去。
- ズーム抑止はviewport設定とtouch-action: manipulationへ一本化し、イベント抑止による押下状態の張り付き・遅延を回避。
- ボタンは移動・縮小・トランジションなし。押下中だけ約9%の内側暗色を即時表示。
- 攻撃ボタンも位置・大きさは固定し、押下中だけ約11%の内側暗色を表示。
